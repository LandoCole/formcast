- Task 1: Style rejects NaN/inf/<=0 for font_size and min_font_size, and an explicitly set min_font_size above a numeric font_size (Ruling D). An unset min is lowered to a smaller numeric font_size (Style(font_size=5) gives min 5); set_style with only font_size takes min(existing min, new size). All 207 archived eval templates (eval/results/templates.tar.gz) still load under these rules. revise() and build_template() both return SessionResult (use .template). The agent Session builds OpContext without widget_kinds (agent code is frozen), so the kind check applies only to callers that pass widget_kinds (OpContext.from_template(t, form_map) does).
- Task 2: resolve() record-level rules. unmapped_data flags leaf schema paths (scalar/enum/date/scalar-array, plus a list-of-objects path as one table) that have a non-missing value and aren't covered by a mapped field; a mapped table covers only its column keys (an uncovered column with data is flagged as `table[].col`), an unmapped table is flagged once at the table path. unknown_keys is one info warning listing schema-style paths of undeclared keys, skipped for objects where validation already reports "Additional properties". A bad table row's `invalid` goes in TableResolved.warnings (path = table path, row index in the message), its cells still exist with text None. Field warnings carry the field's page/rect; `missing` carries `path` only when the field has a single source path. Source.join is a separator applied only when the post-transform result is a list (no list_joined note then).
- Task 3: fit_text shrinks only on width (single line), on height+max_lines (multi-line), or on cell width+height (comb); a numeric font_size is never height-checked for single line. Multi-line overflow reports `lines` as the wrapped count at min_font_size. Comb cell width = rect width / n with no PAD; comb uses the widest glyph of the (cut) text. max_len and comb combine as min(). `\n` is a hard paragraph break when wrapping. pymupdf.get_text_length(text, fontname="helv", fontsize=...) works in PyMuPDF 2.0.
